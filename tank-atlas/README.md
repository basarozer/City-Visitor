# Tank Atlas

Türkiye rafineri ve tank envanteri.

Uygulama: https://tank-atlas-basar.bsrozr.chatgpt.site

Kendi ChatGPT hesabınızla giriş yapın. Veriler cihazlar arasında ortak bir veri tabanında tutulur. Bu açık GitHub deposu sadece uygulama kodunu içerir; tank kayıtlarınız burada yayınlanmaz.

`source/` uygulamanın kaynak kodudur. Çalışan uygulama sunucu ve D1 veritabanı kullanır, doğrudan GitHub Pages üzerinde çalıştırılamaz. `index.html` özel uygulamaya giriş bağlantısıdır. City-Visitor ana sayfası değişmemiştir.
